## 💡 The Solution

**EDU-PAY** is a smart, student-friendly web platform that makes college fee payment **instant, paperless, and stress-free** — from any device, at any time.

> *One click. Fees paid. Receipt in hand. Class attended.* ✅

## 🔄 How EDU-PAY Works

```
  STEP 1  ───────────────────────────────────────────────
  🎒  Student opens EDU-PAY on mobile or laptop

  STEP 2  ───────────────────────────────────────────────
  📝  Enters:  Name  ·  Roll Number  ·  Department  ·  Year

  STEP 3  ───────────────────────────────────────────────
  💰  System fetches total fee amount + any fine details

  STEP 4  ───────────────────────────────────────────────
  🏦  Student pays via Net Banking — instant & secure

  STEP 5  ───────────────────────────────────────────────
  🧾  Receipt generated immediately — payment confirmed

  STEP 6  ───────────────────────────────────────────────
  📊  Google Sheets auto-updates — accountant notified
```

## 📊 System Flow

```
  Student Input
       │
       ▼
  ┌─────────────────────────────────────────────┐
  │  Name + Roll No. + Department + Year        │
  └──────────────────────┬──────────────────────┘
                         │
                         ▼
              Fetch Fee Details from
                  Google Sheets
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
         Base Fee              Fine Amount
              │                     │
              └──────────┬──────────┘
                         ▼
                   Total Payable
                         │
                         ▼
                  Net Banking Payment
                         │
                         ▼
              ┌─────────────────────┐
              │  Receipt Generated  │  ← Student
              │  Sheets Updated     │  ← Accountant
              │  Advisor Notified   │  ← Advisor
              └─────────────────────┘
```
